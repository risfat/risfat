### 👋 About me

I'm a software engineer in **Dhaka, Bangladesh** with **5+ years** of professional experience: Flutter-first since 2023, full-stack web before that. I'm currently a **Software Engineer II at Astha IT**.

I like the problems that sit between the app and the network: video startup time, streaming, real-time data, and keeping apps fast on weak connections. Outside my day job I build complete products on my own, from the Flutter app to the Next.js web app and the Node.js or Python backend.
